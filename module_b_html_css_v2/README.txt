КУХНИ МИРА — ВАРИАНТ 2 (HTML + CSS)

Как открыть:
1. Распакуйте архив.
2. Откройте login.html в браузере.
3. Переходите по разделам через левое меню.

Состав:
- login.html — экран авторизации
- recipes.html — список рецептов, фильтры, сортировка и пагинация (макет)
- recipe-form.html — форма рецепта, состав и шаги
- ingredients.html — справочник ингредиентов
- categories.html — категории рецептов
- steps.html — шаги приготовления
- orders.html — список заказов
- styles.css — общие стили

Это отдельный дизайн: светлая кремовая палитра, терракотовые акценты,
типографика с засечками и боковая навигация.

Важно: по просьбе сделана только HTML/CSS-верстка. Поэтому кнопки,
фильтры, сохранение данных, авторизация, REST API и серверные операции
показаны как элементы интерфейса, но не выполняют серверную логику.
В проекте нет JavaScript, PHP, Python, MySQL и CSS-фреймворков.

Внешние фотографии загружаются с Unsplash при наличии интернета.
